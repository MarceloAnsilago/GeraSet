FLASK

STREAMLIT
.\.venv\Scripts\python -m pip install -r .\requirements.txt
.\.venv\Scripts\python -m streamlit run .\app.py
Abra no navegador: http://localhost:8501

Para parar qualquer servidor, pressione Ctrl+C no terminal.
Para executar os dois ao mesmo tempo, use um terminal para cada app.
