# GeraSet Flask

Versao Flask separada do app Streamlit.

## Rodar

```powershell
cd C:\Users\76395499220\Desktop\prog\GeraSet
.\.venv\Scripts\pip install -r .\flask_version\requirements-flask.txt
.\.venv\Scripts\python .\flask_version\app.py
```

Depois abra:

```text
http://localhost:5000
```

Para remover esta versao, apague somente a pasta `flask_version`.
